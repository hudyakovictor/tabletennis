# Быстрый запуск — v2 Contact Flow

1. Распакуйте весь ZIP в новую папку. Предыдущую версию оставьте для отката.
2. Откройте `table-tennis-topspin.html` или `play/index.html` в браузере с WebGL. Либо используйте приложенный отдельно HTML v2.
3. Если мобильный просмотрщик файлов не исполняет HTML/WebGL, разместите `play/index.html` на статическом HTTPS-хостинге и откройте ссылку в браузере. Вложения чата иногда показывают только предварительный просмотр.
4. На старом адресе сайта после обновления выполните полную перезагрузку/закройте старую вкладку, чтобы не играть в прежней копии.

## Управление

- Мышь: курсор перемещает ракетку; удерживайте левую кнопку и проведите для удара. Неподвижный клик сам не отбивает мяч.
- Телефон: нажмите и сделайте свайп; второй палец отменяет жест.
- Подача: первое нажатие по игровому полю запускает подброс. Можно сразу провести и отпустить — жест дождётся разрешённого контакта на падении. Либо отдельно запустить подброс и затем ударить свайпом рядом с мячом.
- Вверх — верхнее вращение; вниз — нижнее; выраженная боковая дуга — боковое. Высота мяча, скорость и длина движения определяют конкретный удар. В безопасном профиле короткое мягкое движение/удержание также доступны для защиты.
- Форхенд/бэкхенд определяется стороной позиции с учётом ведущей руки. Смена хвата/руки — в настройках.

## Для разработчика

```sh
npm ci
npm run build
npm test
npm run test:browser
npm run test:input
npm run test:contact
npm run stress:contact
npm run bench:contact
```

Запускайте браузерные тесты по очереди. Для синтетического CPU-теста в Linux/macOS:

```sh
CPU_SLOWDOWN=6 CONTACT_REPORT=test-results/evidence/contact-ab-cpu6.json npm run bench:contact
```

Исходники: `tt/src/`. Главные изменения: `38_paddle_motion.js`, `40_swipe.js`, `55_ai.js`, `70_game.js`, `75_feedback.js`. Подробности, ограничения и методика замеров — в `CONTACT-FLOW-v2.ru.md`.

Для локального сервера:

```sh
python3 -m http.server 8000 --directory play
```

Открыть `http://localhost:8000`. Сервер на вашем компьютере не публикует игру в интернете сам по себе.
