# План «×2» — TOPSPIN ARENA (26.10.2026)

Оценка: ~81/100. Слабые места: метагейм (73), реиграбельность (74), эмоция момента очка (80 → чисто, но стерильно).
Цель плана: прочное ядро + живая долгосрочная петля + драма матча. Всё без бэкенда (localStorage + существующие посты iframe).

## Реализовано в этом батче

### 1. Драма счёта без мусора в кадре (game, 70_game.js)
- Суффиксы баннера очка: `· СЕРИЯ ×N` (3+ очка подряд от игрока), `· ДЬЮС`, `· МАТЧБОЛ[!]`.
- Толпа подхватывает серию: растущие аплодисменты + setCrowd-уровень. Никаких частиц — только текст у табло и звук
  (контракт пользователя: в момент удара/очка минимум эффектов поверх кадра).

### 2. Живые «Задания дня» (host: career.js + scr_hub.js + scr_battle.js)
- Статичная заглушка QUESTS (с фальшивым прогрессом!) заменена на настоящие ежедневные миссии:
  пул из 8 миссий, детерминированный выбор 3 по дате, прогресс из реальных итогов матчей
  (победы / идеальные / удары / смеши / лучший розыгрыш / точность).
- Награды забираются в хабе (Wallet), состояние в S.daily с дневным авто-сбросом.
- В итогах матча карточка «Задание дня выполнено: …» соединяет матч с метой.

### 3. Экран итогов: ход матча + максимальная скорость (host: scr_battle.js)
- Последовательность очков (посты 'point') собирается в матче; на экране итогов — SVG-график «Ход матча»
  (кумулятивная разница очков: кто вёл и когда перелом).
- Плитка «Макс. скорость» (км/ч, maxSpeed из matchEnd-payload) + «Точность» + «Победные».

### 4. Регрессионная сеть (game/tt/tools/audit.cjs)
- +3 статических анализа: пул миссий валиден/уникален; res получает seq/maxSpeed и вызывает Daily.tick;
  баннерные акценты (СЕРИЯ/МАТЧБОЛ) присутствуют в 70_game.js.
