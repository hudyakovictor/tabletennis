# Архитектура TTU (оболочка + движок)

Как устроен проект после рефакторинга 2026-07-26, куда класть новый код и какие контракты нельзя ломать. Mobile-first: телефон — основная платформа, десктоп и развёрнутый Telegram — поддерживаемые, но вторичные режимы.

## Два слоя, один файл на выходе

```
source/
  build.py            # собирает оболочку → source/index.html (один файл)
  src/                # оболочка (меню, мета, магазин) — слои ниже
  game/               # WebGL-движок (свой build: game/tt/build.py → встраивается в оболочку)
docs/ARCHITECTURE.ru.md
```

Оболочка при сборке встраивает готовый HTML движка строкой `GAME_HTML` и показывает его в `<iframe srcdoc>` (`#gamelayer`). Связь — только `postMessage` с полем `__tt:1` (контракт — `game/tt/src/92_embed.js`, принимающая сторона — `source/src/services/game_host.js`). Никаких общих глобалов между слоями.

## Слои оболочки (`source/src/`)

Порядок в `build.py:order` = порядок загрузки; файл, не попавший в список, в бандл не войдёт. Слои зависят только вниз:

| Слой | Что там | Примеры |
|---|---|---|
| `core/` | платформа и примитивы без игровых знаний | `util.js` ($, fmt-обёртки), `i18n.js`, `state.js` (сейвы), `platform.js` (TGX: Telegram, haptic, fullscreen), `audio.js` (Sfx), `ui_core.js` (Sheet/Router/Wipe/Nav), `dev.js` (dev-only, не локализуется) |
| `locales/` | словари `ru.js`, `en.js` (см. i18n) | |
| `data/` | чистые данные и каталоги без DOM | `leagues.js`, `catalog.js` (маркетплейс), `season.js` |
| `ui/` | переиспользуемый рендер: иконки, арт предметов, фон, FX | `art.js`, `item_art.js`, `bg.js`, `fx.js`, `ui.js` |
| `services/` | состояние и правила поверх data | `economy.js` (кошелёк), `career.js` (лиги/миссии/ачивки), `game_host.js` (мост в движок) |
| `engine2d/` | лёгкий 2D-канвас демо-режим хаба (фолбэк, не WebGL) | `engine.js` |
| `screens/` | экраны: один файл = один экран, регистрируется `Router.def('<id>', {...})` | `hub`, `shop`, `pass`, `ranks`, `profile`, `settings`, `matchmaking`, `match`, `training`, `result` |
| `main.js` | бут: порядок инициализации и сплэш. Всегда последний в order | |

CSS: `css/base.css` (устройство, навигация, листы, десктоп/альбомные правила) + `css/screens_{hub,battle,meta,misc}.css` по экранам; порядок — `build.py:CSS_ORDER`.

## Контракты, которые нельзя ломать

1. **i18n.** Весь видимый текст оболочки — только через `t('key')` / `I18n`. Ключи лежат в `src/locales/ru.js` и `en.js`; наборы ключей обязаны совпадать, это проверяет `source/tests/i18n.test.cjs` (`npm test` в `source/`) вместе с покрытием: тест сканирует код на `t('...')`, поля `tk/nk/dk/sk/tagk` и динамические семейства `kind./cur./rarity./item./league./ach./mission./cal.`. Плюралы — объекты форм (`{one, few, many, other}`), выбор — `Intl.PluralRules`; числа — `I18n.num()` (Intl.NumberFormat кэшируется), таймеры — `I18n.left(ms)` с формами «12д 4ч / 5ч 12м / 05:12» от величины. Добавить язык = новый словарь + строка в сегменте языков настроек. Движок: свой словарь `ET` в `game/tt/src/03_i18n.js`, язык приходит от хоста (`window.__TT_LOCALE` при старте + postMessage `locale` при смене; стики-сообщение в `game_host.js`). Внутренние коды движка (причины очков вида `АУТ`/`В СЕТКУ`, RU-причины оболочки из `ZoneStats`) — **коды, а не тексты**: отображаемый текст получается маппингом код→ключ рядом с местом показа.
2. **Сейвы.** `SAVE_VERSION` в `core/state.js`; форма сейва чинится `repairShape`, переезд между версиями — функции в `MIGRATIONS[n]` (n = версия, С которой переезжаем). Перед миграцией пишется `ttu-v2.bak`. `save()` — дебаунс 250 мс; `saveNow()` — на `visibilitychange:hidden`/`pagehide` и после трат валюты. Битый JSON не должен ронять бут: фолбэк — `.bak`, затем дефолт.
3. **Каталог (маркетплейс).** Товар: `{id, nk:'item.*', kind:'rubber|blade|trail|table|bundle', r:'rare|epic|leg', price:{cur:'coins|gems', amt}|null, col, st:{параметры}, tagk?, from?, to?}`. `price:null` — не продаётся за валюту (сундуки/пасс/ивенты). Окно продажи — `from/to` (timestamp), `Catalog.shop(now)` фильтрует истёкшие и сортирует срочные вверх. Имена — только ключи: `itemName/kindName/rarityName`, цена — `priceTag`. Новый тип товара = значение `kind` + ключ `kind.<kind>` в обоих словарях + арт в `ui/item_art.js`.
4. **Хост↔движок.** Команды и события перечислены в шапке `92_embed.js`. Стики-настройки (`quiet/mute/hint/quality/rm/debug/locale`) хост повторяет новому iframe после потери GPU-контекста (`game_host.recover`); текущий режим (`match/train/lobby/attract`) — тоже. Новое стики-сообщение = добавить тип в список стики в `game_host.send` и в список «не будящих» в `92_embed.js`, если оно не должно поднимать рендер.
5. **Ввод и ориентация.** Мобайл — свайп (pointer events, `touch-action:none` на канвасе движка), десктоп — мышь (движок сам определяет режим подсказок `detectInputMode`). Альбомный телефон в матче — шторка `#rotate` (только `pointer:coarse` + малый рост). Десктоп ≥760px: меню — колонка `min(460px,54vh)`, а `body.in-game` разворачивает `#deviceWrap` на всё окно (матч и тренировка). Полноэкранный Telegram — `TGX.toggleFullscreen()` (кнопка в настройках), работает только по жесту.

## Производительность (бюджет)

- Движок спит, когда слой скрыт (`sleep`/`wake`, лобби — облегчённый `lobby`-режим без автоматча); частицы — фиксированный кольцевой буфер без аллокаций в кадре (`61_particles.js`).
- Сейв — дебаунс; `Intl`-форматтеры кэшируются; словари грузятся все сразу (они малы), разбивка по экранам не нужна при текущем размере.
- Тяжёлое (арт, музыка) не должно попадать в первый кадр хаба: лобби-арена стартует после сплэша.

## Как добавить…

- **Экран:** файл в `screens/`, `Router.def('id', {render, mount, leave})`, текст — ключами, стили — в профильный `css/screens_*.css`. Полноэкранным экранам — `full: true`.
- **Товар:** запись в `data/catalog.js` (`SHOP` или `BONUS_ITEMS`) + `item.<id>` в двух словарях. Никакого рендера цен руками — `priceTag`.
- **Язык:** словарь в `src/locales/<lang>.js` (полный набор ключей — тест паритета подскажет недостающие), словарь в `03_i18n.js` движка, опция в сегменте языков (`screens/settings.js`).
- **Модуль движка:** файл `NN_name.js` в `game/tt/src/` + строка в `JS_ORDER` (`game/tt/build.py` сам упадёт, если файл на диске не в списке); зависимости тестов — `game/tests/helpers.cjs` подгружает `03_i18n`/`61_particles` автоматически.
- **Функцию карьеры/тренировки:** правила — в `services/` (оболочка) или `65_train.js`/`58_coach.js` (движок); шаги тренировки — `TRAIN_STEPS` с ключами `drill.*`.

## Известные долги (транш 2)

- Меню/мета автономной страницы движка (`80_ui.js`: меню, онлайн, настройки внутри игры) всё ещё RU-строки; в embed-режиме игроку видны только тренировочная панель и HUD — они локализованы. Локализовать при выводе автономной страницы в прод.
- Dev-панели (`core/dev.js`, dev-листы в `result.js`/`game_host.js`) намеренно не локализуются.
- Причины очков движка — RU-коды в протоколе; при переводе протокола на стабильные коды обновить маппинги в `Trainer.onFault` и `screens/battle_common.js` одновременно.
