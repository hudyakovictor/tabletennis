# Roadmap до завершения (без онлайн-режима и интеграции Telegram)

Стек: офлайн-игра vs ИИ, Telegram Mini App (мобильный первый). Демо-заглушки (кошелёк, покупки Stars, «друзья») остаются демо.

---

## P0 — блокеры релиза

1. **Звук и музыка сквозная.** Есть только синтезированные SFX в точках контакта (Sfx.reveal/win/…). Добавить: фоновые музыкальные лупы (хаб/матч/результат), полный набор UI-звуков (кнопки, листание, открытие сундуков, покупка), игровые звуки (ударах по мячу, стол, сетка, свист аудитории), микс с приоритетом (музыка приглушается в матче), уважение mute/game-host `quiet`, предзагрузка после первого тапа.
2. **Производительность на реальных устройствах.** Проверка на Pixel 6a / iPhone 12 и слабом Android: стабильные 50–60 FPS в матче и в сундук-анимациях, профиль памяти (iframe + WebGL), авто-снижение качества (quality bridge уже есть — замерить пороги), батарея/нагрев за 15 минут. swiftshader-замеры не засчитываются.
3. **Экономика и баланс — цифры под замок.** Кривая XP/рейтинга, цены в магазине, награды из сундуков и пассов, стоимость ускорения; сложность ИИ по диапазонам рейтинга (включая «разгон» после первого винрейта), гарантия прогресса без доната (монеты из матчей покрывают накладки за X сессий).
4. **Влияние экипировки на геймплей.** Сейчас накладки/основания — чисто косметика, но показывают статы [скорость/вращение/контроль]. Либо (а) честно ввести влияние на физику (маппинг в PH-константы ракетки ±%), либо (б) пометить «коллекционный предмет, не влияет на матч». Решить и реализовать.
5. **FTUE-финалка.** Обучение → первый быстрый матч → награды: замерить время до «крючка», первый матч против мягкого ИИ (first_win форсится — убедиться, что срабатывает в боевом пути), демо в хабе не мешает, подсказки после 3 промахов не спамят.
6. **Настройки — полный набор.** Громкости музыка/SFX раздельно, вибрация, качество графики (авто/выс/сред/низ), подсказки коуча вкл/выкл, камера по умолчанию (3 пресета), сброс прогресса с подтверждением,reduce-motion.
7. **Сохранения — броня.** Версия схемы + миграции, восстановление после битого localStorage (бэкап-копия и graceful reset), автосейв после каждого матча/покупки (сейчас частично), защита от двойного списания валюты (Wallet.spend идемпотентен).

## P1 — до «полностью готово»

8. **Оставшийся арт → рендеры:** сундуки 4 тиров (сейчас SVG), ячейки наград пасса (gem/coin pile), наборы гемов/монет в магазине, мини-арт карточки-награды в результате, баннеры событий/заданий.
9. **Задания и события.** Сейчас «Задания» и «События» — статичные заглушки. Ежедневные: 3 квеста (сыграй матчи, попади топспином N раз, выиграй розыгрыш 8+), прогресс-бары, награды монетами/гемами, ротация раз в сутки; сезонное событие с трек-наградой.
10. **Профиль довести:** история матчей с деталями (лог уже пишется — нужен экран/шит с прокруткой и фильтром), достижения: завершить набор и раздачу наград (есть каркас в career.js), карточка «техника» — финальные формулировки и подсказки тренировок.
11. **Реплеи и итоги.** Последний розыгрыш сохраняется/показывается — добавить кнопки «ещё раз»/«пропустить», стабильный кадр через 240fps-запись (проверить на слабых), лейблы качества отображаются всегда, метка лучшего удара.
12. **Сундуки — финал цикла.** Таймеры → push-эквивалент локального напоминания (без TG — нельзя, класть в TODO-блок «online»), ускорение за гемы подтверждение, анимация открытия: 3 этапа наград с фейерверком по редкости, «пропустить».
13. **Доступность.** reduce-motion (уменьшить bob/пчелу/радар), увеличенный шрифт не ломает сетки, контраст текста ≥ 4.5, haptic-отключение, крупные зоны тапа уже проверены аудитом — держать в e2e.
14. **Мобильные квирки.** Чёлки/safe-area на iOS и Android, проигрывание звука после resume из фона, WebGL context loss на дешёвых (восстановление есть — вычистить визуальные артефакты), ориентация/поворот во время матча (ресайз зоны!), foldables.
15. **Коуч и подсказки — границы.** Автоподсказки: лимит 2 за матч, отключаются после N матчей или при винрейте >55%, тексты финальные (редактура), ZoneStats саморазмер: проверить на идеальной игре (сжатие капчура до планки).

## P2 — выпускная шлифовка

16. **Диета сборки.** Сейчас index.html ≈ 1.6 МБ: вычистить неиспользуемые SVG/функции art.js (оставшиеся), субсет шрифтов (кириллица+латиница), дедупликация CSS, ленивый запуск карьеры/пасса (рендер по запросу уже частично).
17. **Дефолты правил → прод.** match_rules v4 значения проверить игровыми сессиями (не только тестами): captureRadius/depthTolerance/fwd/back/side — финальный сет, «девовые» ползунки спрятать за ?dev=1 (уже), RulesLink оставить только в dev.
18. **Пайплайн релиза.** --long e2e (ttips, tcoach, tzstats) обязателен pre-merge, автоматический бамп версии в билде, CHANGELOG, скриншот-регресс для ключевых экранов (есть shots/, завести сравнение), итоговое README.
19. **Юридика/контент.** Иконки и шрифты — лицензии (Manrope/Unbounded SIL OFL — ок), возраст, копирайт сгенерированного арта (свои генерации — ок), privacy stub (локальные данные).
20. **Оффлайн-полнота.** Проверка полного запуска и матча без сети (PWA-кеш за рамками), отключённый tg.js — graceful degrade (уже негативно работает), cold start < 3 с на современном телефоне.

### Что отсутствует из «старых» задач и почему
- Онлайн-мультиплеер, друзья с реальными игроками, ELO-матчмейкинг, кланы, рейтинг с сервером — вне скоупа.
- Реальные Stars-платежи, вебхуки бота, облачные сохранения через Bot API — вне скоупа (демо-режим кошелька остаётся).
- Турниры/мероприятия с серверным ивентом — заменено офлайн-событиями (п. 9).

### Быстрая оценка объёма
- P0: ~7–10 рабочих сессий (звук+баланс+настройки+сейвы — самое ёмкое).
- P1: ~8–12 сессий (арт+квесты+реплеи+квирки).
- P2: ~3–5 сессий.
Итого до «1.0»: ~18–27 сессий в текущем темпе.
