# Аудит страниц TTU · оценка 0–100 по 10 факторам

Шкала: **0** — отсутствует/сломано · **50** — рабочее, но серое · **100** — эталон.
Художественная оценка основана на референсе `uploads/ind0ex.html` (неймо-glasmorphism,
эффекты: pop-in, glow-акценты, иллюстративные иконки, русская типографика).

Факторы: **F1** визуал/иллюстрация · **F2** иконография · **F3** читаемость типографии ·
**F4** иерархия/композиция · **F5** цвет/контраст · **F6** анимация/живость ·
**F7** информативность · **F8** действие/CTA · **F9** согласованность стиля ·
**F10** техническая чистота (переполнения, обрезки, адаптив).

Балл страницы = среднее.

**Сделано в этой итерации:** имя «TABLE TENNIS ULTIMATE» над столом; стол поднят в кадре;
подписи режимов перенесены НАВЕРХ карточек; иконки режимов заменены на иллюстративные
спрайты из sprite-sheet (быстрый = огненный мяч, онлайн = скрещённые ракетки,
практика = корзина мячей, карьера = медаль); лента друзей: 3 друга + «+» → рефералка,
статус «играет» = мини-красная ракетка с жёлтой ручкой, оффлайн = ч/б аватар.

**План улучшений:**
1. Hero-карусель из 2–3 слайдов (событие / витрина магазина) с автопрокруткой, как в
   ind0ex — даст контекст и возвращаемость (F1, F6, F8).
2. Карточка «Продолжить матч» поверх hero, если матч-стейдж существует (F7, F8).
3. Блок «Твой прогресс»: 3 мини-метрики (серия, xp до уровня, позиция лиги) под play-зоной (F7).
4. Параллакс-сдвиг стола по акселерометру/наводке — глубина сцены (F6).
5. Дороги-прогресс лиги: заменить плоский bar на сегментированный с отметками-милями (F1, F4).
