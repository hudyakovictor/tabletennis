## 1. Что было сделано (этап 1 глобальной переработки)

### base.css — полностью переписан с чистого листа
Удалено всё устаревшее (старые `.b3`, `.pnl`, `.hud`, `.modebtn` и т.д.). Новая дизайн-система:
- **Типографическая иерархия**: h1 (40px) → h2 (28px) → h3 (20px) → body (16px) → body-sm (13px) → caption (11px)
- **Семантические цвета**: accent-primary/success/danger/warning/gold/violet — по функции, а не по оттенку
- **Доступность**: цель касания 48×48px, контраст WCAG AA, focus-visible на всех интерактивных элементах
- **Компоненты**: btn (primary/success/danger/ghost/hero/icon), card, empty-state, skeleton, progress-bar, list-item, toast
- **Top HUD**: профиль, прогресс рейтинга, валюты, уведомления — в одной строке
- **Bottom nav**: 4 вкладки, чёткие иконки, активное состояние
- **Sheet**: модальные панели снизу с grab-хендлом

### Hub (главное меню) — полностью переверстан
**До**: 5 равнозначных карточек режимов, Freunde-лента, сундуки, подарки — всё смешалось в одну кучу
**После**:
- Одна доминирующая цель: "Играть" — 3 крупные кнопки режимов (free/ranked/practice)
- Вторичные действия компактно: задания, подарок, друзья, настройки — в сетке 2×2
- Баннер лиги: одна строка с названием лиги и рейтингом
- Нет лишних иллюстраций, нет мусора

### Match (игра) — отладка убрана
**До**: slowmo, diag-mark, devBtn, уведомления, пауза — всё вперемешку
**После**: только уведомления и пауза. Отладочные кнопки полностью удалены из интерфейса.

### Match HUD — полностью переписан
**До**: шрифт 11px, низкий контраст, нечитаемо в динамике
**После**: счёт 40px в центре, имена 15px, энергия читаема, техника удара чётко видна

### Result (итог матча) — обновлён
- Бейдж исхода (победа/поражение/завершено)
- Крупный счёт с именами
- Прогресс рейтинга и XP
- Кнопки с правильными размерами (48px)
