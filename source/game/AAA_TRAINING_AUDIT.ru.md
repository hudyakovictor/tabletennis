## 2. Главные проблемы (почему не AAA)

1. **Нет визуального обратного отклика** — игрок не чувствует "я попал" или "я промахнулся" кроме текста.
2. **Нет демонстрации движения** — только SVG-диаграмма жеста, нет призрачной руки в 3D, которая показывает, как провести свайп.
3. **Нет адаптивности** — если игрок не может сделать флик, обучение не предлагает упростить или показать ещё раз.
4. **Нет системы целей** — прохождение урока не даёт звёзд, нет бронзы/серебра/золота.
5. **Нет повторения ошибок** — после ошибки игрок переходит к следующему мячу, а не отрабатывает проблемный момент.

## 3. План переработки (этапы)

### Этап A — Сок и визуальный отклик (высокий эффект, неделя)
- [x] Частицы при правильном контакте в обучении (цвет по удару)
- [x] Импакт-флеш в точке контакта (зелёный = верно, красный = ошибка)
- [x] Shake камеры при ошибке контакта
- [ ] Звуковой отклик успеха/ошибки (уже есть audio.ui — требует интеграции с juice.type)

### Этап B — Призрачная рука и демонстрация (высокий эффект, 1-2 недели)
- [x] Призрачный палец/жест в 3D, показывающий ожидаемый свайп перед мячом
- [ ] Анимация ракетки-тренера, повторяющая эталонный жест
- [ ] Подсветка зоны нажатия мягким свечением

### Этап C — Адаптивная сложность (средний эффект, 1 неделя)
- [x] Если 2 ошибки подряд — показывать кольцо и призрачный жест автоматически (hintContact/autoHint)
- [ ] Уменьшение скорости мяча после 2 ошибок
- [ ] Подсказка "начни ниже/выше/левее/правее" на основе dx, dy

### Этап D — Система целей и наград (средний эффект, несколько дней)
- [ ] Звёзды 1-3 за урок (по точности, таймингу, попыткам)
- [ ] Прогресс-бар модуля с звёздами
- [ ] Экран награды после модуля

### Этап E — Разбор ошибок и повтор (высокий эффект, 1 неделя)
- [ ] Режим "повтори последний мяч" после ошибки
- [ ] Экран разбора ошибки с траекторией 실제 удара vs эталона
- [ ] Кнопка "покажи ещё раз" на фидбеке
