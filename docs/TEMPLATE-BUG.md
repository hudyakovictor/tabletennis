# Шаблон универсальной карточки пункта (бага / идеи / гипотезы)

Заполняется перед первым совещанием. Без этой карточки пункт не принимается в реестр и не обсуждается по `docs/PROTOCOL-EXPERTS.ru.md`.  
ID присваивается хранителем реестра по формату `CT-XX-###` (см. `docs/PROTOCOL-BUGS.ru.md`, раздел 3).
