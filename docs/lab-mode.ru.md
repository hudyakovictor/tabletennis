# TOPSPIN LAB — отладочный режим

Основной (и пока единственный) режим игры. Старое меню и отдельная калибровка удалены:
игра сразу начинается в режиме отладки, а зоны, сила и тайминг проверяются прямо в розыгрыше.

## Как поиграть

```bash
npm run build      # собрать play/index.html и table-tennis-topspin.html
npm run serve:lab  # http://localhost:8080/ (можно открыть с телефона в той же сети)
```

`play/index.html` самодостаточен: один файл, без внешних ассетов, работает и с `file://`.

## Ядро

| Что | Где | Правило |
| --- | --- | --- |
| 8 ударов | `tt/src/lab/10_lab_shots.js` | свайп вверх/вниз/влево/вправо + 4 диагонали; кривая линия выпрямляется до ближайшей из восьми |
| сила | там же | физическая длина свайпа в мм: слабый → сетка/своя половина, обычный → середина, сильный → край, слишком сильный → за стол |
| подача | `labSolveServe` | своя половина, затем чужая; направление и тип выбирает игрок в настройках |
| зона контакта | `labBallZone` | по ВРЕМЕНИ до плоскости удара, а не по прямоугольнику в пространстве |
| цвет мяча | `40_lab_game.js` | белый → зелёный (можно бить) → красный (уже поздно) |
| камера | `applyCamera` | подгоняется под стол; единственная настройка — дистанция, отдельно для телефона и десктопа |
| история | `LabStore` | удары, промахи и подачи раздельно, плюс сводка по каждой игре |

Ракетка на мобильном появляется только во время касания. Зона удара на экране не рисуется —
она видна только по цвету мяча (так и просили: подсветка отвлекает).

## Тесты

```bash
node --test tests/lab.test.js
```

Проверяются: распознавание 8 направлений и выпрямление кривого жеста, четыре полосы силы,
то, что слабый удар реально не долетает, а слишком сильный улетает, легальность всех подач,
окно белый→зелёный→красный, раздельный учёт ударов/промахов/подач и сохранение истории.

## Что дальше тюнить

Только по данным истории (`ИСТОРИЯ → СКОПИРОВАТЬ JSON`), а не набором слайдеров:
если в истории видно, что «обычные» удары уходят в сетку, двигаем `powerZeroMm`/`powerFactor`,
а не добавляем новую ручку в интерфейс.
