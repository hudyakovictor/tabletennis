# Меню-хаб: 100 анализов и 100 симуляций

## Откуда взяты идеи

Источник — приложенный каталог интерактивных ассетов (160 демонстраций, 20 групп).
Взяты конкретные техники, а не «вдохновение»:

- пружина из переключателя таймфреймов (57) и сжатия волатильности (15);
- морфинг индикатора из нижней навигации (28) и дока с увеличением (50);
- каскад из скелетонов загрузки (81);
- прожектор из бенто-панели (39) и лучи (125);
- дешифратор терминов (56), счётчик XP (47);
- конфетти (120), монетный дождь (25), тосты (54), рипл и жидкая капля (82);
- аврора-фон (96), стекло и док (77–78), 3D-тилт (1), радиальное меню (77),
  карусель (92), хроматический сбой (90), лента с инерцией (122),
  прогресс-кольцо (104), кольцо фокуса (87), живой предпросмотр (47, 109).

## Модель

Шесть критериев: читаемость, отклик, характер, производительность, доступность,
мобильность. Базовые веса умножаются на приоритеты платформы (mobile-first,
Telegram Mini App) и нормируются. На каждом прогоне веса и оценки приёмов
получают шум; приёмы ранжируются; результаты усредняются по 100 прогонам.

Два раунда: первый по «сырым» приёмам, второй — после правок, которые первый
раунд подсказал. Ниже сходятся 200 прогонов (100 + 100).

Бюджет по классам нагрузки: idle ≤ 4, enter ≤ 2, event ≤ 6.

## Правила, которые вышли из симуляций

1. Пружина — единственная кривая для «жизни» интерфейса: она даёт остановку без пролёта.
2. Всё, что двигает содержимое, двигается вместе. Частичное движение внутри карточки
   ломает тап: палец оказывается между кнопками (проверено на мобильном прогоне).
3. Прозрачность наследуется мгновенно: `transition: all` на кнопке задерживал
   наследуемую `visibility` на 80 мс, и тап не доходил до цели.
4. Тяжёлые фоны (аврора, лучи, стекло) не анимируются, когда хаб закрыт — иначе
   композитор считает их в каждом кадре матча.
5. `prefers-reduced-motion` выключает декоративное, но не логику: экраны, счётчики,
   счёт и статусы остаются.
6. Один экран за раз: смена раздела закрывает предыдущий, иначе меню читается
   как слоёный пирог.
