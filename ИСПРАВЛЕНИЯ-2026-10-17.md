# Анализ ошибок и исправления TOPSPIN ARENA

Дата: 17 октября 2026. Проверены актуальные `tt/src/*`, обе опубликованные HTML-страницы и WebSocket relay. Старые отчёты в репозитории использованы только как контекст, не как доказательство работоспособности нынешней версии.

## Результат

Исправлены ошибки управления, переходов между режимами, карьеры, сохранений, звука, правил подачи, сборки и сетевых комнат. Добавлены воспроизводимые тесты и CI. Обе опубликованные страницы пересобраны из одних исходников.

**Не утверждается, что устранены все ошибки игры.** В частности, полноценный онлайн-геймплей остаётся незавершённым (см. ниже).

| Карьера | Изменённые перками настройки попадали в постоянные предпочтения | Сохраняются исходные пользовательские assist/posAssist/difficulty |
| Карьера | Завершённый забег удалялся UI, затем снова записывался игрой | Терминальный checkpoint удаляется самим `Career.save`; приостановленный checkpoint не удаляется при pagehide |
| Карьера | Невалидный индекс/повторный вызов могли ломать переходы или повторно засчитать результат | Валидация целочисленных индексов и текущего состояния |
| Карьера | Повреждённые сохранения могли загрузить несуществующий турнир/отрицательный раунд | Проверка структуры, диапазонов, перков и сетки противников |
| Интерфейс карьеры | Сохранялись старые кнопки противников, кнопка «ВПЕРЁД» оставалась на выборе, поражение подписывалось прошлым турниром | Очистка и синхронизация экранов, правильный индекс турнира, отмена отложенного перехода при выходе |
| Сохранения | Основной ползунок области попадания вообще не записывался | `hitZone` включён в сериализацию |
| Настройки | Произвольные поля сохранения сливались в настройки без диапазонов | Белый список известных типов/значений; ограничение чисел и исключение произвольных ключей |
| Звук | Переключатель не сохранял изменение, после загрузки показывал неверную иконку | Сохранение состояния и правильная иконка при запуске |
| Звук | При создании AudioContext терялись сохранённая громкость и mute; unmute всегда ставил 0.9 | Громкость хранится до инициализации и используется при init/unmute; проверена реальная перезагрузка |
| Подача | Любое попадание в сетку сразу считалось let, даже если мяч оставался на своей стороне | Let только после корректного второго отскока на стороне принимающего; неудачная подача — потеря очка |
| ИИ | На уровнях 0/1 скорость и вращение менялись уже ПОСЛЕ расчёта легальной траектории | Удалена постобработка; уровень сложности по-прежнему задаётся параметрами `OpponentAI` до решения удара |
| Награды | Наблюдение за ботами могло приносить награду за матч | Demo не вызывает начисление наград и статистики завершённых матчей |
| Время/рендер | Невалидный dt мог отравить состояние | Фильтрация dt и ограничение большого шага; камера инициализируется до первого рендера |
| Relay | Третий клиент перезаписывал заполненную комнату; неизвестный код создавал комнату вместо ошибки | Проверка существования/вместимости до выхода из прежней комнаты; генерация уникального кода |
| Relay | Уход хоста оставлял «мёртвую» комнату; повторный join мог присоединить игрока к себе | Закрытие комнаты без хоста, идемпотентный join, корректное освобождение места гостя |

| Relay | Гость мог отправлять серверные события начисления очков | `state` и `point` пересылаются только от хоста к гостю |
| Сетевой клиент | Позднее событие старого сокета затирало новое соединение | Каждый обработчик проверяет актуальность сокета; таймер ping очищается |
| Сетевой клиент | После выхода сохранялись роль host и старые пакеты; входящий `ball:null` не останавливал мяч; вращение живого мяча не обновлялось | Сброс сессии, применение spin/dead ball, копирование счёта без общей ссылки |
| Сетевой клиент | Повреждённый пакет мог частично испортить координаты | Валидация векторов/счёта до изменения состояния |
| Сетевая UI | Разрыв соединения оставлял матч продолжаться без противника | Возврат в меню с уведомлением; онлайн помечен экспериментальным |

## Что реально проверено

### Автоматические тесты — 24/24

Команда: `npm test`.

- Совпадение обеих HTML-страниц со свежей сборкой исходников.
- Восстановление сетки/раунда карьеры, переходов турнира, набора перков.
- Повторная загрузка без накопления бонусов, восстановление базовых настроек.
- Невалидные сохранения и индексы, повторное завершение матча, терминальный и приостановленный checkpoints.
- Отмена свайпа, сохранение громкости при mute/unmute.
- Калибровка отскока и очистка переиспользуемого результата прогноза.
- Жизненный цикл клиента WebSocket, валидация пакетов.
- Настоящий локальный relay с тремя WebSocket-клиентами: заполненная/неизвестная комната, маршрутизация, права хоста, уход гостя, уход хоста, повторный вход, повреждённый JSON.

Для проверки, что тесты действительно находят прежние ошибки, первоначальные 15 core-сценариев запускались на исходниках HEAD до правок: **11 падений, 4 успешных**. После исправлений весь текущий набор проходит.

### Chromium/WebGL — 64/64

Команда: `npm run test:browser`.

Два размера экрана: **1280×760** и **390×844**. Тесты запускают настоящий HTML, WebGL-рендерер и игровые классы, а не подменённую игровую логику. Случайность в браузерном стенде фиксирована для воспроизводимости.

Проверены запуск и отрисовка, меню, горячие клавиши, пауза/настройки/blur, отмена ввода, обучение и изоляция режимов, UI карьеры, повреждённые настройки, правила подачи, сохранение рассчитанной скорости ИИ, отсутствие наград demo. Пройдены **10 полных демо-матчей до 5 очков: все 5 уровней × 2 размера экрана**. Отдельно проверены реальная перезагрузка страницы с сохранёнными ползунками/mute и первый пользовательский клик, создающий AudioContext.

Необработанных JavaScript-исключений в этом прогоне нет. Проверки размера экрана не заменяют тесты на физическом телефоне и реальные жесты пользователя.

## Известные оставшиеся ограничения

1. **Полноценный онлайн-матч не исправлен.** Исходная реализация пересылает координаты ракетки гостя, но не превращает его жест в удар на хосте; у гостя параллельно работает собственная логика матча. Недостаточно менять только relay: нужны авторитетная симуляция, протокол жестов/подачи, преобразование сторон и общий автомат матча. Исправлены инфраструктура комнат и устойчивость сообщений, НЕ весь PvP. Публичный relay извне не проверялся.
2. Некоторые описанные перки карьеры (усталость, замедление кольца, специальное замедление времени) не имеют полноценного применения в игровом коде. Они не объявлены исправленными в этом проходе.
3. Не выполнены замеры FPS/задержки солвера на физических Android/iOS, полное прохождение всех тренировочных жестов человеком и статистическая перебалансировка пяти уровней после устранения порчи траекторий.
4. Регрессионный набор проверяет конкретные ошибки, а не доказывает отсутствие всех возможных багов или строгое соответствие всем правилам ITTF.
