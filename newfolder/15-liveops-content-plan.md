# LiveOps, контент-план и сообщество

## Player feedback loop

- Сбор отзывов внутри игры.
- Структурированная система: собрать → отсортировать → приоритизировать.
- Мониторинг ревью и соцсетей.
- Ответ на негативные ревью — часть retention.

## Community management

- Discord или Telegram-канал сообщества.
- Регулярные анонсы патчей и known issues.
- Эскалационный путь для критичных жалоб.

## Patch pipeline

Ритм:

- Day-1 patch;
- Week-1 hotfix;
- bi-weekly stability patches.

Pipeline: fix → test → build → deploy → announce, за часы, не дни.

Beta-ветка для тестирования перед продом.

## Контент-план

- План на 6–12 месяцев вперёд.
- Сезонные ивенты, привязанные к праздникам.
- Устойчивый ритм: обновление каждые 4–6 недель.

## Монетизация и экономика

- Виртуальная валюта, цены, баланс.
- Battle pass, ивенты, сезонный контент.
- Экономические метрики: sink/source валюты, инфляция.
- Платёжные провайдеры по регионам.

## CRM-дашборд

Помимо чата с директором, в CRM есть дашборд.

### Разделы дашборда

- Обзор: DAU, сессии, выручка, алерты.
- Игроки: когорты, retention, сегменты.
- Экономика: валюта, покупки, sink/source.
- Маркетинг: каналы, кампании, ROAS.
- ИИ: статус зон, лимиты, стоимость.
- Fraud: очередь кейсов.
- Контент: план обновлений, статус.

### Виджеты

- Графики с выбором периода.
- Таблицы с сортировкой и фильтром.
- Карточки с ключевыми метриками.
- Алерты с приоритетом.

## Telegram-бот как второй канал

Бот дублирует ключевую информацию из дашборда.

### Push

- Critical алерты — сразу.
- Warning алерты — сразу, без звонка.
- Ежедневная сводка в 09:00.

### Pull

Команды для запроса данных без захода в CRM.

Бот не заменяет дашборд, а дополняет его.
