# Чек-лист перед запуском

## Безопасность

- [ ] API-ключи только на сервере
- [ ] Нет секретов в клиентском бандле
- [ ] Авторитетный сервер для игровой логики
- [ ] Валидация ввода на сервере
- [ ] Rate limiting
- [ ] CORS настроен
- [ ] CSP настроен
- [ ] Роли и права разделены
- [ ] Аудит всех действий

## ИИ

- [ ] ИИ только на бэкенде
- [ ] Игрок не видит упоминаний ИИ
- [ ] Зоны изолированы
- [ ] Шаблоны промптов готовы
- [ ] Валидация выходов по JSON Schema
- [ ] Лимиты токенов на зону
- [ ] Аудит запросов к провайдерам
- [ ] Human-in-the-loop на действия

## Законы и санкции

- [ ] ПДн граждан РФ хранятся в РФ
- [ ] Поле region во всех таблицах с ПДн
- [ ] Согласие на телеметрию
- [ ] Согласие на ИИ-анализ
- [ ] Retention policy
- [ ] Право на удаление
- [ ] DPA с провайдером ИИ, если отправляются ПДн
- [ ] План DR и бэкапов

## Инфраструктура

- [ ] Один сервер на старте
- [ ] Схемы БД разделены по зонам
- [ ] Региональное поле в БД
- [ ] Возможность вынести админку отдельно
- [ ] Возможность разделить БД по регионам

## Запуск

- [ ] Тесты пройдены
- [ ] Логи пишутся
- [ ] Дашборды работают
- [ ] ИИ-зоны отвечают
- [ ] Директор собирает сводки
- [ ] Чат с владельцем работает
- [ ] Нет утечек секретов
