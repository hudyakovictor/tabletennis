# AI-провайдеры

## Текущее решение

На старте не используется единый AI Router.

Каждая зона получает собственный API-ключ и собственный набор запросов к провайдеру.

Это проще, надёжнее и позволяет запуститься без лишней сложности.

## Провайдеры

| Провайдер | Плюсы | Риски |
|---|---|---|
| OpenRouter | Много моделей, единый API, оплата криптой | Зависимость от аптайма |
| NVIDIA NIM | Бесплатные лимиты, хорошие модели | Жёсткие лимиты |
| GPT4Free | Бесплатно | Нестабильно, серая зона |
| Прямые API | Стабильно, SLA | Оплата из РФ, риск блокировки |
| Локальные (vLLM, Ollama) | Полный контроль, нет внешних логов | Нужен GPU |

## Рекомендация по зонам

| Зона | Провайдер | Модель |
|---|---|---|
| Ops | OpenRouter | маленькая быстрая |
| Fraud | OpenRouter или NVIDIA | средняя |
| Balance | OpenRouter | средняя |
| Market | OpenRouter | средняя |
| Lab | GPT4Free или NVIDIA | дешёвая |

## Fallback

Позже можно добавить цепочку:

```text
primary -> fallback1 -> fallback2 -> local
```

На старте это не обязательно.

## Лимиты

У каждой зоны свой дневной лимит:

- Ops: 100k токенов;
- Fraud: 200k токенов;
- Balance: 300k токенов;
- Market: 200k токенов;
- Lab: 500k токенов.

При исчерпании лимита зона просто молчит до следующего дня.

## Безопасность

- Не отправлять ПДн в модель.
- Анонимизировать данные перед отправкой.
- Не отправлять сырые логи с гео или fingerprint.
- Хранить логи запросов у себя.
- Для критичных зон использовать провайдера с zero-retention.

## Стоимость

Учитывать:

- input tokens;
- output tokens;
- кэш;
- batch;
- лимиты.

Batch API даёт до 50% скидки при ответе в течение 24 часов.

Кэш промптов снижает стоимость повторного входа до 10% и ниже.
