# Чат с директором

## Роль директора

Директор — это не главный ИИ, который управляет всеми зонами.

Директор — это слой сводок и общения с владельцем.

Владелец пишет только директору.

Директор читает короткие структурированные сводки от зон.

Директор не имеет доступа к сырым логам.

## Что видит директор

Директор видит только:

- свежие сводки от зон;
- последние 48–72 часа истории;
- текущие открытые инциденты;
- последние принятые решения владельца;
- активные A/B-тесты.

Директор не видит:

- сырые JSONL-логи;
- полные истории других зон;
- персональные данные игроков;
- API-ключи;
- внутренние промпты зон.

## Sliding window

История чата ограничена 48–72 часами.

Более старые сообщения:

- удаляются из активного контекста;
- сохраняются в архивной БД;
- не попадают в новый запрос к модели.

Это уменьшает стоимость и не даёт контексту распухать.

## Постоянный блок

Кроме истории чата, у директора есть короткий постоянный блок состояния:

- открытые инциденты;
- активные A/B;
- последние решения владельца;
- текущие приоритеты.

Этот блок не является историей чата. Он обновляется отдельно.

## Шаблоны промптов

Каждый запрос к директору состоит из:

1. Статичной шапки: роль, границы, запреты, формат ответа.
2. Динамического блока: свежие сводки зон.
3. Динамического блока: последние сообщения чата.
4. Динамического блока: текущий вопрос владельца.

Пример структуры:

```text
[SYSTEM]
Ты — директор админ-панели TOPSPIN ARENA.
Ты работаешь только с данными, которые тебе передали.
Ты не имеешь доступа к сырым логам.
Ты не можешь менять игру.
Ты выдаёшь ответ строго в JSON-формате.

[ZONE SUMMARIES]
{fresh_zone_summaries}

[CHAT HISTORY]
{last_48_72h_messages}

[USER QUESTION]
{owner_question}
```

## Формат ответа директора

```json
{
  "status": "ok | warning | critical",
  "summary": "краткий вывод",
  "findings": [
    {
      "zone": "balance",
      "issue": "рост OUTSIDE_ZONE на быстрых подачах",
      "confidence": 0.82,
      "recommended_action": "проверить MATCH_RULES для touch"
    }
  ],
  "next_questions": [
    "показать теплокарту по Android"
  ]
}
```

## Безопасность

Данные из логов — недоверенный контент.

Они передаются в отдельном блоке `DATA`, а не как инструкции.

Ответ модели всегда проходит JSON Schema-валидацию.

Невалидный ответ попадает в карантин, а не в чат.
