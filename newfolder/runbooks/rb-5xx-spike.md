# Runbook: `rb-5xx-spike` — Аномальный всплеск ошибок 5xx и таймаутов

## Триггер
Доля HTTP `5xx` или таймаутов шлюза выросла более чем на **50% за 5 минут** относительно скользящего baseline, либо `p99 latency` превысил baseline на `2σ`.

## Симптомы
- Игроки видят ошибку сохранения результата матча или долгое открытие Mini App.
- В Telegram-бот пришёл алерт `CRITICAL` со ссылкой на `rb-5xx-spike`.

## Пошаговая диагностика
1. Нажать **Ack** в Telegram-боте или на вкладке **Observability**, чтобы остановить повторные эскалации.
2. Проверить состояние золотых сигналов (Saturation CPU / RAM / блокировки БД / очередь событий):
   ```bash
   curl -s http://127.0.0.1:4100/api/health
   curl -s http://127.0.0.1:4100/api/admin/observability/prometheus | grep topspin_
   ```
3. Если идёт неконтролируемый шторм запросов на матчмейкинг — включить **Режим техработ (`maintenance_mode = ON`)** в разделе «Техработы и Пуши» (меню и новости останутся работать, вход в матч временно закроется с автоматическим пушем игрокам).

## Команды отката
```bash
git log -n 3 --oneline
git revert HEAD --no-edit && systemctl restart topspin-backend
```
