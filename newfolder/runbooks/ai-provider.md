# Runbook: AI_PROVIDER / карантин

## Триггер
Провайдер недоступен, лимит исчерпан или ответ не прошёл JSON Schema-валидацию.

## Что происходит автоматически
- Невалидный ответ записывается в `ai_quarantine` и НЕ попадает в чат/сводки.
- При сбое внешнего API используется локальный детерминированный анализ (если `AI_LOCAL_FALLBACK=1`).
- При исчерпании дневного лимита внешние вызовы прекращаются.

## Диагностика
1. ИИ-зоны → последние запросы: HTTP error, latency, fallback.
2. Карантин: проверить причину и признаки prompt injection.
3. Проверить ключ конкретной зоны в `.env` (не пересылать его в чат/логи).
4. Проверить дневной расход токенов и модель.

## Восстановление
Исправить ключ/модель/base URL и перезапустить CRM. Пометить карантин проверенным после разбора. Не ослаблять JSON Schema ради «прохождения» ответа.

## Откат
Отключить внешний ключ зоны: CRM продолжит работать на локальном анализе без внешних данных.
