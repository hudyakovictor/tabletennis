# Runbook: ERROR_5XX

## Триггер
Доля 5xx выше порога (по умолчанию 5%) при достаточном трафике.

## Диагностика
1. Список маршрутов и кодов в Ops.
2. Сравнить с временем деплоя и фоновыми задачами.
3. Проверить логи игрового бэкенда по request ID; не отправлять ПДн в AI.
4. Проверить доступность БД, диск, файловые дескрипторы и внешние зависимости.

## Смягчение
Открыть инцидент; при массовой недоступности матчей включить maintenance с ETA, если он известен. Автоматический пуш создастся при смене режима.

## Откат
Откатить последний релиз игрового бэкенда; после восстановления выключить maintenance — клиент получит пуш восстановления.

## Проверка
5xx ниже порога, нет роста повторов платежей (идемпотентность сохранена).
