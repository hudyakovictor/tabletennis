# Runbook: `rb-webgl-context-loss` — Массовые потери WebGL-контекста (`glLost`) и просадка FPS

## Триггер
Доля сессий с `webgl_losses > 0` превысила **3%**, либо средний `fps_avg` упал ниже **45 FPS** с уходом `render_scale_min` в `0.60`.

## Симптомы
- Мобильные WebView (особенно бюджетные Android и старые iOS в Telegram) сбрасывают GPU-контекст и показывают экран восстановления арены.

## Пошаговая диагностика
1. В **Зоне Ops** проверить распределение `webgl_losses` и `fps_p10` по `device_type` (`android` vs `ios`).
2. Проверить последние изменения шейдеров, HDR-буферов (`RGBA16F`) или размера текстур ассетов витрины.

## Команды проверки и отката
```bash
cd ../source/game && npm run test:browser
```
