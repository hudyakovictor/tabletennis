# Runbook: CRASH_RATE

## Триггер
Crash rate выше порога (по умолчанию 3%).

## Диагностика
1. **Ops → Сборки**: найти сборку и устройство с максимумом крэшей.
2. Сопоставить `ops_crashes.reason`: WebGL context lost, OOM, iframe reload, unhandled promise.
3. Проверить длинные задачи и FPS, а не только количество крэшей.
4. Проверить последние изменения рендера, replay, аудио и сохранений.

## Смягчение
- Открыть инцидент; при массовой регрессии вернуть стабильный `active_build`.
- Включить known issue; пуш — только если игрокам нужно немедленное действие.
- Не менять физику/правила «для маскировки» крэша.

## Откат
Откатить сборку игрового бэкенда и очистить affected client cache по инструкции релиза.

## Проверка восстановления
Crash rate ниже порога два окна детектора подряд; нет новых тикетов с той же сигнатурой.
