# Runbook: P95_LATENCY

## Триггер
p95 HTTP latency выше `p95_latency_ms` или аномально выше baseline.

## Диагностика
1. Разложить по маршрутам в `ops_http`: p50/p95/p99 и 5xx.
2. Проверить ping регионов и долю сессий с ping >100 мс.
3. Проверить saturation: CPU/RAM игрового сервера, размер очереди, соединения.
4. Отделить сетевую задержку Telegram WebView от времени обработки backend.

## Смягчение
- Ограничить неcritical batch-задачи и ingestion при насыщении.
- Включить ближайший региональный endpoint через конфиг игрового бэкенда.
- При регрессии релиза — откатить backend, а не увеличивать таймауты бесконечно.

## Откат
Вернуть предыдущий региональный роутинг/релиз. Сохранить session affinity при reconnect.

## Проверка
p95 возвращается к baseline; нет роста таймаутов и повторных подключений.
