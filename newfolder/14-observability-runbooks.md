# Observability, алерты и runbooks

## Четыре золотых сигнала

- Latency: p50, p95, p99.
- Traffic: RPS, одновременные игроки.
- Errors: 4xx, 5xx, таймауты.
- Saturation: CPU, RAM, connections, queue depth.

## Алерты

Алерты на аномалии, а не на абсолютные пороги.

Примеры:

- рост 5xx на 50% за 5 минут;
- p99 latency выше baseline на 2 сигмы;
- падение DAU на 20% за час;
- всплеск отказов ввода;
- провайдер ИИ недоступен.

## Уровни

| Уровень | Что значит | Действие |
|---|---|---|
| Info | Норма, но заметно | Только в дашборд |
| Warning | Отклонение, не критично | Telegram-бот, без звонка |
| Critical | Сломано, игроки страдают | Telegram-бот + звонок/пуш |

## Runbooks

У каждого алерта — ссылка на runbook.

Runbook содержит:

- триггер;
- симптомы;
- пошаговую инструкцию;
- команды для диагностики;
- команды для отката;
- кого звать.

Runbook лежит в репо, не в Confluence.

## Post-mortem

После каждого Sev-1/Sev-2:

- что случилось;
- почему;
- как починили;
- как предотвратить.

Blameless: без поиска виноватых.

## Инструменты

- Prometheus + Grafana для метрик.
- Loki или ELK для логов.
- OpenTelemetry для tracing.
- Alertmanager для роутинга алертов.

## Telegram-бот

Бот — второй канал доставки, не замена дашборда.

### Push (алерты)

- Critical: сразу, с кнопкой «Ack» и ссылкой на runbook.
- Warning: сразу, без звонка.

### Pull (по запросу)

Команды бота:

- `/status` — общее состояние;
- `/ping` — пинг по регионам;
- `/errors` — последние ошибки;
- `/players` — DAU, сессии;
- `/revenue` — выручка за сегодня;
- `/ai` — статус ИИ-зон;
- `/fraud` — открытые кейсы;
- `/help` — список команд.

Бот не имеет права менять игру. Только читает и показывает.
