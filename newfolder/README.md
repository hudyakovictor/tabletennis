# TOPSPIN ARENA — Admin Panel

Этот каталог содержит проект админ-панели для игры TOPSPIN ARENA.

## Цель

Админка нужна соло-фаундеру, чтобы:

- видеть состояние игры без ручного разбора логов;
- находить проблемы баланса по логам игроков;
- следить за маркетинговыми метриками;
- находить фрод и аномалии;
- принимать решения по данным, а не по ощущениям.

## Главный принцип

ИИ не создаёт уровни, туториалы и игровые режимы. Весь игровой контент проектируется заранее и генерируется детерминированно из настроек игры.

ИИ работает только с уже собранными данными:

- логи ввода;
- телеметрия матчей;
- маркетинговые события;
- платёжные события;
- результаты тестов.

ИИ предлагает выводы и варианты действий. Финальное решение принимает владелец проекта.

## Текущее решение по ИИ

На старте не используется единый AI Router.

Каждая зона получает собственный API-ключ и собственный набор запросов к провайдеру. Это проще, надёжнее и позволяет запустить систему без лишней сложности.

Позже, если появится необходимость, можно добавить общий маршрутизатор моделей.
