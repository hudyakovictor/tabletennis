## Принятые решения

- Настройка темпа: `0 = 0.35x`, `50 = 1.0x`, `100 = 1.25x`, монотонная кусочно-линейная шкала. Ноль не означает паузу. Показывать фактический множитель, а не только условный процент.
- Менять темп симуляции, не импульсы мяча. Жесты измерять по реальным временным меткам; физические окна и события симуляции согласовать с ее временем. Анимации интерфейса, звук и исчезновение подписи работают по реальному времени.
- В соревновательных режимах сохранять единый темп и существующие запреты помощи; не давать одному участнику сетевой игры индивидуально замедлять общую физику.
- После подтвержденного удара игрока показывать `SMASH 10 об/с`: фактический итоговый тип и модуль угловой скорости, деленный на `2*pi`, после всех преобразований контакта. Метка живет 1.5 секунды, коротко подсвечивается и плавно исчезает; никаких исходов полета в этой метке.
- Полный `ShotJournal`, причины отказа и результаты отскоков остаются в диагностике/разборе. Нераспознанный жест и промах не создают метку успешного удара. Отскок и новая ревизия журнала не запускают ее повторно.
- Анимация не создает физический контакт: шаблоны подстраиваются к реальной точке, ориентации и времени контакта. Удалить конфликт между позой для рендера, физики и диагностики.
- Обучение: показ движения -> непрерывная практика -> короткая проверка. Промах в практике не открывает модальное окно; подробный разбор и 3D-просмотр открываются намеренно и безопасно приостанавливают упражнение.

- Исправить смену языка во время матча: обновлять представление, не выполнять цепочку `leave -> quit -> новый матч`. Смена языка и повторный mount не должны конфликтовать с очисткой подписок из `e7b`. Сохранить счет, сессию, паузу, текущую попытку и сетевое соединение.
- Сократить аллокации watchdog, не удалять детекторы. Учет медленных кадров не должен исключать саму просадку FPS. Изображения диагностических попыток по умолчанию выключены; числовой журнал и ручной снимок остаются доступны, явную пользовательскую настройку записи сохранять.

## Миграция и сборка

- Начать с `git status`/diff и baseline-проверок; существующие сбои зафиксировать отдельно от добавленных изменениями. Не коммитить без запроса пользователя.
- Сохранить старые ID ударов/уроков и содержимое сейвов. Добавочные техники не требуют смены версии wire-каталога, если форма сообщений не меняется; иначе согласованно обновить обе стороны bridge, а не только движок.
- Новые настройки вводить через один валидируемый набор defaults/диапазонов; существующий конечный `0` сохранять. Неверные/неизвестные значения нормализовать. Отдельный сброс касается настроек, не инвентаря и прогресса. При изменении формы сохранения нужен штатный шаг `SAVE_VERSION`/`MIGRATIONS` с резервной копией.
- Новые engine-модули, если нужны, добавить в `JS_ORDER` движка и список VM-загрузчика тестов. Не хранить собранные страницы в `source/`, не переносить чужой `node_modules`, React-приложение или Cloudflare-скрипты.
- После завершения пересобрать `play/index.html` из исходников. Самостоятельный `build/engine.html` нужен только для тестов; проверить оба способа загрузки.

## Приемка

- Проверки должны измерять реальные контакты, вращение, отскоки, положение геометрии и события ввода, а не только наличие строки/ID в исходнике.
- Разделять сохраненные отчеты разработчиков и новые воспроизводимые результаты. Не объявлять проблему устраненной по одному успешному примеру или отсутствию предупреждений.
- Подачи игрока: мышь/touch, короткие/длинные жесты, оба знака бокового вращения, небольшая случайная кривизна, ранний старт/отпускание, отмена и повтор, обе руки/хваты, темпы 0.35/1/1.25x, 30/60/120 FPS. Валидный ввод не теряется; неподвижное удержание не дает автоконтакта.
- Подачи бота: все типы и уровни, фиксированные seed, два легальных отскока, фактические `v/w` равны предсказанным, нет сетки/аута из-за неверного решателя, видимая вершина на 360/390/768/1280 px и в landscape. Изменение намеренных ошибок учитывать отдельно.
- Ракетки: низкий прием, боковой удар, подача, замах, сопровождение, шум ИИ, оба хвата/руки. Проверять вершины/опорные границы клинка и рукоятки во времени; рендер и collision используют одну позу. Низкая поза вне стола не дает ложного предупреждения.
- Новые техники: позитивные/негативные граничные тесты короткой дуги/подрезки/второго tap и всех прежних рекламируемых жестов. Проверять реальные prefix-трассы до момента контакта, отсутствие двойного контакта, правильные знаки top/side/back относительно направления полета, no-spin по полному модулю до отскока. Повторить после помощи, экипировки, caps и fallback. Поддельная метка не проходит учебную цель.
- Шаблоны: все 17 импортированных и 3 добавленных профиля, конечность/непрерывность позиции и quaternion, контакт активной накладки на расстоянии радиуса мяча, без двойного offset; корректное отражение руки/хвата и одинаковая поза при 30/60/120 FPS. Сохранить текущие проверки геометрии и реконструкции `strokeFrame` в `paddle-motion.test.js`.
- Preview: циклы/orbit/scrub не меняют снимок мяча, счета, игрового/учебного времени, попыток, журнала и RNG. Переключение урока, закрытие, Esc/клавиши матча, resize, sleep/wake, reduced motion не протекают в игровое управление. Учебные ленты после обратной проекции классифицируются нужным типом; orbit не двигает мировую схему.
- Подпись: только после контакта, правильные тип/цвет/обороты, срок 1.5 реальных секунды на всех темпах; bounce/revision/pointerup не повторяют метку. Она не перекрывает мяч/кнопки и не зеркалится; нижнего технического текста нет; полный журнал сохраняется.
- Звук: один контакт -> один контактный сэмпл, один взмах -> один взмах; успешный удар до отпускания не дает промаха. Проверить iOS/Android unlock, mute/zero/quiet, одновременные события, fallback, отсутствие утечки узлов и проигрывания скрытого preview.
- Обучение: просмотр не влияет на игру/прогресс; пауза/возврат/смена урока/потеря контекста не запускают лишний мяч. Старое освоение сохраняется, новые уроки видны, награда не дублируется. Автоповтор не открывает окна на каждую попытку.
- Все 17 CAL: отсутствующее значение / явный 0 / default / 100 / мусор/NaN/вне диапазона; fresh boot соответствует Reset; reload/recovery/смена языка не меняют счет и предпочтения. Проверить requested/effective настройки в free/ranked/career/check/online, сочетания темпа/инспектора/высоты подброса, mute уже запланированных звуков и ОС reduced motion.
- Производительность: сравнивать p50/p95/p99 на одном сценарии/seed/профиле, отдельно стоимость решателей и кадра, не выбирать только лучший прогон. Зафиксировать аппаратные ограничения headless-проверок.
- Команды реализации: `npm run build`, `npm test`, `npm run test:browser`, `npm run test:academy`, `npm run test:diagnostics`, `npm run test:missshots`, `npm run test:interface`, `npm run test:online` из `source/game/`; `python3 source/build.py` и `node --test source/tests/*.test.cjs` из корня. Для вращения/подач дополнительно `npm run ai:serves` и `npm run watchdog:rally`; эти инструменты дополнить фактическими end-to-end сценариями, не считать изолированную карту подач достаточной.
- Обновить старые тесты, привязанные к нижнему HUD и устаревшему числу уроков, на новый контракт; сохранить все независимые проверки законности/контакта/журнала. Проверить standalone и iframe, desktop/mobile, офлайн, reset/reload и GPU recovery.
